# Week 1 - Batch Scripting Commands Explanation

| Command | Short Explanation |
| :--- | :--- |
| `@echo off` | Hides command execution text to keep the output clean. |
| `echo` | Displays text on the Command Prompt screen. |
| `echo.` | Prints a blank line for better spacing. |
| `pause` | Stops script execution until a key is pressed. |
| `REM` | Adds comments that are ignored during script execution. |
| `mkdir` / `md` | Creates a new directory or folder. |
| `cd` | Changes the current working directory (`cd ..` moves back). |
| `>` | Redirects output and overwrites/creates a file. |
| `>>` | Appends output to the end of an existing file. |
| `type` | Displays the contents of a text file on the screen. |
| `set` | Defines and sets variables. |
| `set /p` | Prompts the user to enter input and stores it in a variable. |
| `set /a` | Performs integer arithmetic calculations. |
| `%var%` | Retrieves the value stored inside a variable. |
| `if` / `else` | Decision-making statements based on conditions. |
| `if exist` | Checks if a specific file or folder exists. |
| `for` / `for /L` | Repeats commands using loops or numeric sequences. |
| `tree /F /A` | Displays the graphical directory structure cleanly. |
